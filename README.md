# Проект автоматизации тестирования веб-приложения Stellar Burgers

1. В проекте UI-тесты для веб-приложения Stellar Burgers.
2. Для их написания использовались Python, фреймворк pytest и Selenium.
3. Установить необходимые зависимости:
    - pip install pytest
    - pip install selenium
4. Команда для запуска всех тестов:
    python -m pytest -s
